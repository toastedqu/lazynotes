# The Journey
During my self-study journey, I frequently faced pushback from my own brain - it never felt right. I kept studying each concept/method in isolation, as if each one were just something to shovel into my head for interviews. That's low-level understanding. I tried to structure my study notes in a systemic, high-level fashion, but it never came out right.

This constant back-and-forth in my head is why the LazyNotes project has stalled and restarted for years. Funny enough, I ran into something quite similar at work very recently — an ultimate objective that keeps shifting, so whatever structure gets built on top of it doesn't hold, and no action is efficient or effective.

I entered the field not to get a job but to build a true AI like Jarvis from Iron Man, and nothing I've been doing has consistently aimed at that goal:
- I need the notes to pass interviews (they did help, sure, but I still don't understand shit.)
- I need the notes to look good so that people can benefit from them (why should I give a fuck about others when I don't even understand shit myself.)
- I do want to become an expert in ML/DL/NLP (but I keep forgetting shit - not because of a lack of practice, but because of a lack of intuitive, systemic understanding.)

So what do I actually want to achieve from all this self-study? And what makes it consistently meaningful & enjoyable?

## Intelligence
The biggest buzzword is "intelligence", because it's not a standalone capability but a set of various brain capabilities (e.g., reasoning, planning, learning, perception, language understanding, etc.) that work together.

My personal definition of "intelligence" is - **the efficiency with which a resource-bounded system converts its priors into effective behavior across unseen samples from the environment**.

- **Finitude**: "Resource-bounded system" means a finite boundary the system has access to. In the sense of AI, there are 2 main resources:
    - **Compute**: Given sufficiently large compute, any problem can be solved via brute-force search. This is NOT intelligence.
    - **Sample**: Given sufficient training samples, any problem can be solved via recalls since the system has seen it before. This is NOT intelligence.
- **Competence**: "Priors" are essentially what the system is capable of, so I call it competence. There are 2 main priors:
    - **Inductive Bias**: The set of assumptions the system uses to make inference on unseen samples. This comes from the system itself without ANY training. I personally believed this was the sole factor of intelligence because I was born with strong inductive bias, but throughout years of failures I realized my arrogance got in my way and I am actually a dumbass due to a lack of:
    - **Acquired Bias**: Knowledge & Experience that the system acquired via training without literal memorization of the samples.
- **Ratio**: "Efficiency" is a ratio of competence over provided resources. This is close to the true definition of intelligence.
- **Interactions**: There are 2 types of "effective behavior" for all systems:
    - **Epistemic**: Knowing. Beliefs. Processes input from the external environment into accurate representations. Answers the question "What is true?" & Fails if wrong.
    - **Instrumental**: Doing. Actions. Generates output to the external environment to obtain utility/reward. Answers the question "What should I do?" & Fails if ineffective.
